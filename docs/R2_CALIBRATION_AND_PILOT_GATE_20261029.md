## 试点设计与停止规则

1. 先两类Python目标（命令注入、路径穿越），使用确有来源、漏洞/修复对与独立审核的窄集合。任何目标/修复字节变化要新case新上下文，不能复用原授权。
2. 同一根因的变异、修复对和多快照不得跨开发/验证/保留组；现有调试用夹具均为开发数据，不能改名当未见保留集。
3. 先强单模型与固定级联同任务/同预算对照；专长跨批稳定性支持后才评自适应路由。不为单模型实验注册假蜂绕过生产readiness，实验与生产账本分离。
4. 每题保存候选/无结论/人工确认、模型served身份、重试、失败、真实usage与实际费用；没有抽样概率/真值不算总体召回。
5. 超预算/超4周、无法独立判断真值、修复对照失效、资格/身份漂移或隔离失败即停止该批并报告，不自动扩样或降低门槛。
6. 即使未见优势也交付结果；按设计方案接受退回固定级联或单强模型，不以模块数量替代效果。
