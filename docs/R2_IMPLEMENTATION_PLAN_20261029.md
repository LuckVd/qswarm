## 语义与兼容

- 旧账本 append-only，未知/无证据继续无结论；新结果不自动回灌旧学习积分。
- process 是开发档，永不成为生产降级途径。
- container 的离线 trial 与生产 verify 明确区分：仅生产入口允许业务落账，trial 只输出工件/报告。
- 授权内容核验不足必须拒绝；调用者无法提供工件库时不得仅凭 artifacts 索引行恢复高可信奖励。新增严格授权协议应版本化，旧凭证不得静默升级。
- 默认配置变更须有迁移和行为说明；不得简单打开资格门后声称生产已具备合格 verifier。

## 验收口径

先红后绿回归测试；同 run 中断可恢复且 done 不重复写；相同 cutoff 的历史报告不受未来状态改变；trial 两档均零模型调用、零业务行/事件；篡改/缺失/错上下文授权零高可信写入；E0 和全量测试准确报告；container 真机项只凭实际运行验收。实验没有效果提升也照实交付，不以增加模块代替结论。
