# SPEC-4 机制仿真器（M0 数学规格）

> 来源：设计文档 v0.3.4 §5/§6/§7/§8.4/§16.7。目标：在写任何 LLM 相关代码之前，用仿真**定稿 params.yaml 全部机制参数**，并验证机制层无结构性缺陷。
> 反目标：不仿真检测精度（那是 smoke 集的职责）；不仿真工程性能。

---

## 0. 关键工程决策：仿真复用内核实现

仿真器**直接调用** `kernel/` 的 `route()` / `promote_scan()` / `agg_cells()` / 自适应 TILT——不是重写一份。理由：仿真通过 = 内核实现通过（顺便是内核的第一轮测试）；两份实现会漂移，仿真失去意义。
仿真世界只负责**生成事件流**（任务、verdict、存款），喂给真实内核；度量从内核输出侧采集。

```
sim_world ──(tasks)──→ kernel.route ──→ sim_verdict_gen ──(deposits)──→ kernel.ledger/cells
                              ↑                                              │
                              └────────── promote_scan（夜间批）←──────────────┘
```

## 1. 仿真世界模型

### 1.1 Agent 池
按 params.yaml roster（6/5/4/3）生成，每只 agent：

```
家族级真实能力 q_f ~ Beta(2, 2)              # 先验均匀偏中
类型级偏移 q_t = q_f + ε_t,  ε_t ~ N(0, 0.10)，clip 到 [0.05, 0.95]
隐藏设定（度量用，机制不可见）：
  - 10% 「真专家」：某家族 q_f ~ Beta(8, 2)（应该被晋升）
  - 10% 「运气型」：q_f ~ Beta(2, 2) 但 verdict 生成带早期正向偏差
  - 5% 「退化型」：T_drift 时刻 q_f ← q_f − 0.25（应该被熄灭）
```

### 1.2 任务流
```
到达：Poisson(λ)，λ 默认 50 任务/仿真日
家族混合：taxonomy.yaml v1_weight 归一化（mem_safety 0.3 权重）
难度：d ~ Beta(2, 3)
模式混合：fast 50% / pr 35% / full 15%
周期重扫抽样：RESSCAN_WEEKLY 生成的任务标记 cache_hit=true（无新 finding，只测路由）
```

### 1.3 Verdict 生成（喂给存款机制的三层信号）
```
真实对错：reporter 判对概率 = q(reporter, node) · (1 − 0.3·d)
S1 投票（3 票，含相关噪声）：
  每票 P(与真相同向) = 0.55 + 0.25·reviewer_q
  同底模相关：ρ = 0.4（同 vote panel 内共享一个噪声项 z_panel，z_agent = 0.6·z_own + 0.4·z_panel）
  权重 0.05–0.1（按 params）
S2（full 档 30% 触达）：
  verified_real：判对 → 0.8；判错 → 0.1（会错标 fp）
  verify_error：1 − 上述，**零存款**（§6.2）——核心灵敏度旋钮，扫描 0.2/0.35/0.5
  verified_fp：仅当"判错且存在阻断证据"，权重 0.5
S3（延迟到达）：
  lag ~ LogNormal(μ=ln(5d), σ=1)，截断 [1d, 30d]
  权重 1.0；错误率 ε3 = 0.05
  触达率：S2 结论的 40%、inconclusive 的 80%
```

### 1.4 存款归属
严格按 §6.5 矩阵实现（系数取 params.yaml deposits 节）：auditor ×1.0 / scout ×0.2 / reviewer ×0.5 / verifier −0.5|+0.25；挥发（prod T_half=30d，exam 15d）；n_eff ≡ 2×(pos_w+neg_w)。

### 1.5 考试播种（§8.4）
仿真开始前对每 agent 每家族模拟入学考（8 题，正确率 = q_f 中心化映射 ±[0.2, 0.5] 权重）；**对照组关掉播种**测冷启动差异。

## 2. 度量定义（公式）

| 度量 | 定义 | 目标 |
|---|---|---|
| 晋升查准 | 被晋升为 active 的格子中，真 q_t 位于该类型前 20% 的比例 | **≥ 0.90** |
| 晋升查全 | 前 20% 真能力格子中，在 500 任务内被晋升的比例 | ≥ 0.70 |
| 中位晋升时长 | 真专家从影子到 active 的任务数中位数 | **≤ 200** |
| 误熄灭率 | 非退化型 active 格子被衰退熄灭的比例 | **≤ 0.05** |
| 退化响应 | 退化型从 q 漂移到熄灭的任务数中位数 | ≤ 150 |
| 探索 regret | 实际路由总对错 vs 全知 oracle 路由的差距 | 随任务数单调收窄 |
| 冷启动长度 | 路由期望准确率首次超均匀基线 +5pp 的任务数（播种 vs 无播种） | 播种 < 50 |
| S2 饥饿传导 | verify_error ∈ {0.2, 0.35, 0.5} 下的中位晋升时长增幅 | ≤ 2× |
| 重放等价 | 任意时点 replay 重建 cells 与在线一致 | 100%（回归项） |

## 3. 实验矩阵（参数扫描）

```
N ∈ {6, 10, 14} × δ ∈ {0.05, 0.10, 0.15} × T_BASE ∈ {0.6, 0.7, 0.8}
  × exam 权重上限 ∈ {0.3, 0.5} × verify_error ∈ {0.2, 0.35, 0.5}
固定：λ=50/日，3 个随机种子重复，取指标均值±std
附加单变量实验：
  - TILT 固定 vs 自适应（§5.4 论证回填）
  - 评审存款系数 REVIEWER_X ∈ {0.25, 0.5, 1.0}（待决#12 定标依据）
  - Thompson sampling 对照组（同参数，路由换 TS，比 regret——§5.4 的实验承诺）
```

## 4. 输出物

1. `params.yaml` 定稿回填（满足全部目标的参数组；多组可行时取中位晋升时长最短者）；
2. `sim_report.md`：各度量对目标的达成表 + 参数敏感性曲线数据（CSV）+ Thompson 对照结论；
3. 内核回归测试集：route/promote_scan/agg 的黄金用例（从仿真轨迹抽样 20 条断言）。
